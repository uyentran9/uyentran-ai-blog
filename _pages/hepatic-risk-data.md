## 📊 Dataset Overview

- Clinical tabular dataset  
- Target: **C, CL, D**  
- Multi-class classification problem  

---

## ⚠️ Data Challenges

- Severe **class imbalance**  
- Missing values in multiple columns  
- Mixed feature types (numerical + categorical)

---

## 🔍 Observations

- Majority class: **C (~68%)**
- Minority class: **CL (~2–3%)**
- High risk of misclassification for minority class  

---

## 💡 Implication

- Requires **robust validation strategy**
- Need models that handle imbalance well  
- Careful feature handling is essential

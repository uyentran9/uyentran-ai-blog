## 🧠 Overview

This project develops a **machine learning pipeline** to predict patient outcomes from clinical tabular data.

---

## 🎯 Problem

- Multi-class classification: **C, CL, D**
- Strong **class imbalance**
- Missing values in clinical features
- Need robust generalization

## 💡 Key Insights

- Tree-based models outperform linear models  
- Cross-validation is critical for stability  
- Class imbalance strongly affects minority class performance

# 🧩 Phần 1 – Data Representation & Variables

## 🎯 1. Biến (Variables)

Python không yêu cầu khai báo kiểu. Biến được gán qua `=`.

```python
x = 10
name = "Uyen"
active = True
score = 3.75
```

- `=` là gán, không phải “bằng”.
- Python là *dynamic typing* → kiểu phụ thuộc vào giá trị.

# 📉 Phần 7 – Softmax & Numerical Stability

## Softmax

$$
\text{softmax}(z_i)=\frac{e^{z_i}}{\sum_j e^{z_j}}
$$

```python
import math

def softmax(v):
    expo = [math.exp(x) for x in v]
    total = sum(expo)
    return [x/total for x in expo]
```

## Overflow / Underflow

```python
math.exp(1000)  # overflow → inf
```

### Fix bằng cách trừ max:

```python
def stable_softmax(v):
    m = max(v)
    exps = [math.exp(x - m) for x in v]
    total = sum(exps)
    return [x/total for x in exps]
```

# 🧼 Phần 8 – Clean Code (PEP8)

- 4 spaces indentation  
- `snake_case` cho biến/hàm  
- `PascalCase` cho class  
- `UPPER_CASE` cho hằng số  
- Dòng ≤ 79 ký tự  

Ví dụ:

```python
def compute_area(radius):
    pi = 3.14159
    return pi * radius ** 2
```

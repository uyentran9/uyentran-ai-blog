## **2.1 Variables & Data Types (Chi tiết đầy đủ)**

### 🔹 **1. Variable (Biến) – Định nghĩa**

~~~python
variable_name = value
~~~

**Ví dụ:**
~~~python
age = 25
~~~

## **2. Python Data Types (Các kiểu dữ liệu cơ bản nhất)**

Dưới đây là 7 kiểu dữ liệu quan trọng nhất trong Python, dùng trong phần lớn mọi chương trình.

---

## **📌 2.1.1 Integer (`int`)**

### ✔ Định nghĩa  
Số nguyên (positive, negative, hoặc 0), không chứa phần thập phân.

### ✔ Ví dụ:
~~~python
age = 30
year = 2025
temperature = -5
~~~

### ✔ Kiểm tra kiểu:
~~~python
type(age)  # <class 'int'>
~~~

---

## **📌 2.1.2 Floating point number (`float`)**

### ✔ Định nghĩa  
Số thực có phần thập phân.

### ✔ Ví dụ:
~~~python
pi = 3.14159
weight = 52.7
gold_price = 2450.99
~~~

### ✔ Kiểm tra kiểu:
~~~python
type(pi)  # <class 'float'>
~~~

---

## **📌 2.1.3 String (`str`)**

### ✔ Định nghĩa  
Chuỗi ký tự — dùng nhiều trong NLP, chatbot, xử lý text.

### ✔ Ví dụ:
~~~python
name = "Victoria Tran"
greeting = "Hello, world!"
course = "AIO 2025"
~~~

### ✔ Một số thao tác:
~~~python
"Hello " + "Uyen"      # nối chuỗi
name[0]                # truy cập ký tự đầu tiên: 'V'
~~~

---

## **📌 2.1.4 Boolean (`bool`)**

### ✔ Định nghĩa  
Chỉ có thể là **True** hoặc **False**.  
Dùng trong điều kiện, kiểm tra logic.

### ✔ Ví dụ:
~~~python
is_student = True
passed_exam = False

age = 25
is_adult = age >= 18   # True
~~~

---

## **📌 2.1.5 List (`list`)**

### ✔ Định nghĩa  
Danh sách có thứ tự, **thay đổi được (mutable)**, có thể chứa nhiều kiểu dữ liệu.

### ✔ Ví dụ:
~~~python
scores = [90, 85, 70]
mixed = [10, "Uyen", True, 3.14]
names = ["Uyen", "Victoria", "Tran"]
~~~

### ✔ Truy cập phần tử:
~~~python
scores[0]    # 90
~~~

### ✔ Thay đổi phần tử:
~~~python
scores[1] = 88
~~~

---

## **📌 2.1.6 Dictionary (`dict`)**

### ✔ Định nghĩa  
Dữ liệu dạng **key–value**, giống JSON.  
Siêu quan trọng trong API, NLP, ML.

### ✔ Ví dụ:
~~~python
student = {
    "name": "Uyen",
    "age": 24,
    "major": "Statistics"
}
~~~

### ✔ Truy cập giá trị:
~~~python
student["name"]   # "Uyen"
~~~

---

## **📌 2.1.7 Tuple (`tuple`)**

### ✔ Định nghĩa  
Danh sách **không thay đổi được** (immutable).  
Dùng cho dữ liệu cố định hoặc return nhiều giá trị.

### ✔ Ví dụ:
~~~python
coordinates = (10, 20)
rgb = (255, 200, 100)
~~~

### ✔ Truy cập:
~~~python
rgb[0]   # 255
~~~

---

## **📌 2.1.8 Set (`set`)**

### ✔ Định nghĩa  
Tập hợp **không thứ tự**, **không trùng lặp**.

### ✔ Ví dụ:
~~~python
unique_numbers = {1, 2, 3, 3, 3}
print(unique_numbers)   # {1, 2, 3}
~~~

### ✔ Kiểm tra membership:
~~~python
3 in unique_numbers   # True
~~~

# 🧠 2.2 Conditional Statements — Câu lệnh điều kiện (if / elif / else)

Câu lệnh điều kiện giúp chương trình **ra quyết định** dựa trên dữ liệu.  
Đây là phần cực kỳ quan trọng trong Python, dùng ở mọi nơi: ML pipeline, ETL, chatbot, web backend, automation,…

---

# 🎯 2.2.1. Ý nghĩa & cách hoạt động

Python chạy:

1. `if` → kiểm tra điều kiện đầu tiên  
2. nếu **đúng**, chạy block code và **bỏ qua** tất cả các điều kiện sau  
3. nếu **sai**, chuyển qua `elif`  
4. nếu tất cả đều sai → chạy `else`

👉 Chỉ **1 block** được chạy trong toàn bộ chuỗi if–elif–else.

---

# 🧩 2.2.2. Cú pháp chuẩn (cheatsheet)

~~~python
if condition1:
    # code chạy khi condition1 đúng
elif condition2:
    # code chạy khi condition2 đúng
elif condition3:
    # code chạy khi condition3 đúng
else:
    # chạy khi tất cả điều kiện đều sai
~~~

---

# 🚀 2.2.3. Ví dụ cơ bản nhất

~~~python
age = 20

if age >= 18:
    print("Bạn là người lớn.")
else:
    print("Bạn là trẻ em.")
~~~

**Output:**
~~~
Bạn là người lớn.
~~~

---

# 🧪 2.2.4. Ví dụ thực hành có nhiều điều kiện

~~~python
score = 85

if score >= 90:
    print("Hạng A")
elif score >= 80:
    print("Hạng B")
elif score >= 70:
    print("Hạng C")
else:
    print("Hạng D")
~~~

**Output**
~~~
Hạng B
~~~
---

# 🧨  2.2.5. Pitfalls (lỗi thường gặp)

## ❌ 5.1 Dùng dấu "=" thay vì "=="
~~~python
if x = 5:     # ❌ Sai — "=" là gán, không phải so sánh
~~~

Đúng:
~~~python
if x == 5:    # ✔️
~~~

---

## ❌ 5.2 Quên dấu ":" ở cuối dòng if
Sai:
~~~python
if x > 10
    print("Hi")
~~~

Đúng:
~~~python
if x > 10:
    print("Hi")
~~~

---

## ❌ 5.3 Sai thụt dòng (indentation)
Sai:
~~~python
if x > 0:
print("Positive")   # Sai vì thiếu indent
~~~

Đúng:
~~~python
if x > 0:
    print("Positive")
~~~

---

# 🧮 6. Ví dụ nâng cao: nested conditions (lồng nhau)

~~~python
age = 25
is_student = True

if age >= 18:
    if is_student:
        print("Người lớn + Sinh viên")
    else:
        print("Người lớn nhưng không phải sinh viên")
else:
    print("Trẻ em")
~~~

**Output**
~~~
Người lớn + Sinh viên
~~~
---

# 🧠 2.2.7. Special Trick – Kiểm tra nhiều điều kiện cùng lúc

### ✔ Dùng `and`
~~~python
temp = 30
if temp > 25 and temp < 35:
    print("Thời tiết nóng nhẹ.")
~~~

### ✔ Dùng `or`
~~~python
color = "red"
if color == "red" or color == "blue":
    print("Bạn chọn màu hợp lệ!")
~~~

## 📌 2.2.9. Cheatsheet cuối chương

| Toán tử | Ý nghĩa | Ví dụ |
|--------|---------|-------|
| `==`   | so sánh bằng | x == 5 |
| `!=`   | khác | x != 10 |
| `>`    | lớn hơn | x > 3 |
| `<`    | nhỏ hơn | x < 7 |
| `>=`   | lớn hơn hoặc bằng | x >= 18 |
| `<=`   | nhỏ hơn hoặc bằng | x <= 60 |
| `and`  | cả hai điều kiện đúng | a > 0 and b > 0 |
| `or`   | chỉ cần 1 điều kiện đúng | color == "red" or color == "blue" |
| `in`   | kiểm tra chuỗi con | "hi" in text |

# 🌀 2.3 Loops (Vòng lặp) — for / while

Vòng lặp (loops) giúp chạy lặp đi lặp lại một đoạn mã nhiều lần.  
Trong Python và Machine Learning, loops cực kỳ quan trọng: dùng để duyệt dataset, tính toán vector, train mô hình, xử lý chuỗi,…

Python có 2 loại vòng lặp chính:

- `for` loop → lặp qua từng phần tử  
- `while` loop → lặp cho đến khi điều kiện sai  

---

# 🎯 2.3.0 Vì sao loops quan trọng trong AI/ML?

- Duyệt dữ liệu hàng nghìn mẫu trong ML  
- Tính toán trung bình, tổng, độ lệch chuẩn  
- Xử lý chuỗi NLP  
- Chạy nhiều epoch khi train model  
- Tự động hoá bước trong pipeline  

---

# 🔵 2.3.1 FOR Loop — Lặp qua phần tử trong list / chuỗi

Cú pháp:

~~~python
for variable in iterable:
    # code chạy mỗi vòng
~~~

Ví dụ cơ bản:

~~~python
fruits = ["apple", "banana", "mango"]

for item in fruits:
    print(item)
~~~

**Output**
~~~
apple
banana
mango
~~~

---

## 🎯 Ví dụ nâng cao: tính tổng danh sách

~~~python
numbers = [2, 4, 6, 8]
total = 0

for n in numbers:
    total += n

print("Total =", total)
~~~

**Output**
~~~
Total = 20
~~~

---

## 🎯 2.3.2 Loop với chuỗi (string iteration)

~~~python
text = "AI"
for char in text:
    print(char)
~~~

**Output**
~~~
A
I
~~~

---

## 🎯 Dùng `range()` để tạo vòng lặp số

~~~python
    print(i)
~~~

~~~

1
2
3
4
~~~

# 🔥 2.3.2 WHILE Loop — Chạy đến khi điều kiện False

Cú pháp:

~~~python
while condition:
    # code chạy liên tục
~~~

Ví dụ cơ bản:

~~~python
count = 1

while count <= 3:
    print("Count =", count)
    count += 1
~~~

**Output**
```
Count = 1
Count = 2
Count = 3
```

---

## ⚡ Danger: while loop dễ gây *infinite loop*

Sai:

~~~python
i = 1
while i <= 5:
    print(i)   # ❌ thiếu i += 1 → lặp vô hạn
~~~

Đúng:

~~~python
i = 1
while i <= 5:
    print(i)
    i += 1
~~~

# ⚠️ 2.3.9 Pitfalls — Lỗi thường gặp

# 🔬 2.4.9 Ứng dụng ML: hàm tính accuracy

~~~python
def accuracy(y_true, y_pred):
    correct = 0
    for t, p in zip(y_true, y_pred):
        if t == p:
            correct += 1
    return correct / len(y_true)

print(accuracy([1,0,1], [1,1,1]))
~~~

**Output**
~~~python
0.6666666666666666
~~~

~~~python
def clean_text(text):
    text = text.lower()         # chuyển về cùng chữ thường
    text = text.strip()         # xóa khoảng trắng đầu/cuối
    text = text.replace("\n", " ")  
    return text

raw = "   Hello AIO 2025!  \n"
print(clean_text(raw))
~~~

**Output**
```
hello aio 2025!
```

# 🟦 3.7 CHEATSHEET – Tóm tắt nhanh

| Chức năng | Lệnh |
|----------|------|
| Chữ thường | `text.lower()` |
| Chữ hoa | `text.upper()` |
| Xóa khoảng trắng | `text.strip()` |
| Thay từ | `text.replace("a", "b")` |
| Tách từ | `text.split()` |
| Ghép | `" ".join(list)` |
| Tìm từ | `"hello" in text` |

---

# 🟦 3.8 PITFALLS – Lỗi hay gặp

| Lỗi | Nguyên nhân | Cách sửa |
|-----|-------------|----------|
| `"Hello" != "hello"` | phân biệt hoa/thường | dùng `.lower()` |
| `"hi" in "hiring"` = True | kiểm tra chuỗi con | dùng regex hoặc tách từ nếu cần chính xác |
| `split()` sai khi có nhiều khoảng trắng | double space | dùng `strip()` trước |
| Chatbot không nhận từ | user nhập có dấu | cân nhắc bỏ dấu → dùng `unidecode` |

```
# 🟦 3.6 Mini Chatbot (Theo đúng Module 1)

Đây là bản mở rộng đẹp và đầy đủ:

~~~python
def chatbot(user_input):
    text = user_input.lower().strip()

    if "hello" in text or "hi" in text:
        return "Hi! Mình có thể giúp gì cho bạn hôm nay?"
    elif "help" in text:
        return "Bạn cần trợ giúp gì? Mình đang nghe đây!"
    elif "name" in text:
        return "Mình là Chatbot AIO 2025 phiên bản đơn giản."
    elif "bye" in text:
        return "Tạm biệt nhé!"
    else:
        return "Xin lỗi, mình chưa hiểu ý bạn."

print(chatbot("Hello"))
print(chatbot("Can you help me?"))
print(chatbot("what is your name?"))
print(chatbot("bye"))
~~~

**Output**
```
Hi! Mình có thể giúp gì cho bạn hôm nay?
Bạn cần trợ giúp gì? Mình đang nghe đây!
Mình là Chatbot AIO 2025 phiên bản đơn giản.
Tạm biệt nhé!

## 2. Core Concepts

## **2.1 Variables & Data Types (Chi tiết đầy đủ)**

### 🔹 **1. Variable (Biến) – Định nghĩa**

Biến là tên dùng để lưu trữ dữ liệu trong bộ nhớ.  
Python không yêu cầu khai báo kiểu dữ liệu trước — chỉ cần gán giá trị là tạo biến.

**Cú pháp:**
~~~python
variable_name = value
~~~

**Ví dụ:**
~~~python
age = 25
name = "Uyen"
is_student = True
~~~

---

## **2. Python Data Types (Các kiểu dữ liệu cơ bản nhất)**

Dưới đây là 7 kiểu dữ liệu quan trọng nhất trong Python, dùng trong phần lớn mọi chương trình.

---

## **📌 2.1.1 Integer (`int`)**

### ✔ Định nghĩa  
Số nguyên (positive, negative, hoặc 0), không chứa phần thập phân.

### ✔ Ví dụ:
~~~python
age = 30
year = 2025
temperature = -5
~~~

### ✔ Kiểm tra kiểu:
~~~python
type(age)  # <class 'int'>
~~~

---

## **📌 2.1.2 Floating point number (`float`)**

### ✔ Định nghĩa  
Số thực có phần thập phân.

### ✔ Ví dụ:
~~~python
pi = 3.14159
weight = 52.7
gold_price = 2450.99
~~~

### ✔ Kiểm tra kiểu:
~~~python
type(pi)  # <class 'float'>
~~~

---

## **📌 2.1.3 String (`str`)**

### ✔ Định nghĩa  
Chuỗi ký tự — dùng nhiều trong NLP, chatbot, xử lý text.

### ✔ Ví dụ:
~~~python
name = "Victoria Tran"
greeting = "Hello, world!"
course = "AIO 2025"
~~~

### ✔ Một số thao tác:
~~~python
"Hello " + "Uyen"      # nối chuỗi
name[0]                # truy cập ký tự đầu tiên: 'V'
~~~

---

## **📌 2.1.4 Boolean (`bool`)**

### ✔ Định nghĩa  
Chỉ có thể là **True** hoặc **False**.  
Dùng trong điều kiện, kiểm tra logic.

### ✔ Ví dụ:
~~~python
is_student = True
passed_exam = False

age = 25
is_adult = age >= 18   # True
~~~

---

## **📌 2.1.5 List (`list`)**

### ✔ Định nghĩa  
Danh sách có thứ tự, **thay đổi được (mutable)**, có thể chứa nhiều kiểu dữ liệu.

### ✔ Ví dụ:
~~~python
scores = [90, 85, 70]
mixed = [10, "Uyen", True, 3.14]
names = ["Uyen", "Victoria", "Tran"]
~~~

### ✔ Truy cập phần tử:
~~~python
scores[0]    # 90
~~~

### ✔ Thay đổi phần tử:
~~~python
scores[1] = 88
~~~

---

## **📌 2.1.6 Dictionary (`dict`)**

### ✔ Định nghĩa  
Dữ liệu dạng **key–value**, giống JSON.  
Siêu quan trọng trong API, NLP, ML.

### ✔ Ví dụ:
~~~python
student = {
    "name": "Uyen",
    "age": 24,
    "major": "Statistics"
}
~~~

### ✔ Truy cập giá trị:
~~~python
student["name"]   # "Uyen"
~~~

---

## **📌 2.1.7 Tuple (`tuple`)**

### ✔ Định nghĩa  
Danh sách **không thay đổi được** (immutable).  
Dùng cho dữ liệu cố định hoặc return nhiều giá trị.

### ✔ Ví dụ:
~~~python
coordinates = (10, 20)
rgb = (255, 200, 100)
~~~

### ✔ Truy cập:
~~~python
rgb[0]   # 255
~~~

---

## **📌 2.1.8 Set (`set`)**

### ✔ Định nghĩa  
Tập hợp **không thứ tự**, **không trùng lặp**.

### ✔ Ví dụ:
~~~python
unique_numbers = {1, 2, 3, 3, 3}
print(unique_numbers)   # {1, 2, 3}
~~~

### ✔ Kiểm tra membership:
~~~python
3 in unique_numbers   # True
~~~

---

## **📌 Bảng tóm tắt nhanh**
~~~

| Data Type | Nghĩa | Ví dụ |
|----------|--------|--------|
| `int` | số nguyên | `25` |
| `float` | số thực | `3.14` |
| `str` | chuỗi ký tự | `"Uyen"` |
| `bool` | logic true/false | `True` |
| `list` | danh sách mutable | `[1,2,3]` |
| `dict` | key-value | `{"name":"Uyen"}` |
| `tuple` | immutable list | `(1,2)` |
| `set` | không trùng lặp | `{1,2,3}` |
~~~

### 2.2 Conditional Statements

Control program flow using `if`, `elif`, and `else`:

~~~python
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"
~~~

---

### 2.3 Loops (for / while)

#### For loop:

~~~python
for i in range(5):
    print(i)
~~~

#### While loop:

~~~python
count = 0
while count < 3:
    count += 1
~~~

---

### 2.4 Functions

Functions modularize logic and promote reusability:

~~~python
def greet(name):
    return f"Hello, {name}!"
~~~

## 4. Mini Example: Simple Rule-Based Chatbot

~~~python
def chatbot(user_input):
    text = user_input.lower()

    if "hello" in text:
        return "Hi there! How can I help you today?"
    elif "bye" in text:
        return "Goodbye!"
    else:
        return "I'm not sure how to respond to that."

print(chatbot("Hello"))
~~~
